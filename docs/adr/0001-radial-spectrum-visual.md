# ADR 0001: 円環スペクトラム (リング) 表示を追加し、表示モードとして切り替える

- ステータス: 採用
- 日付: 2026-08-23

## 背景

これまでの表示は「波形」「横並びスペクトラム」「両方」の 3 モードで、いずれも
画面いっぱいの色付き背景の上に描く前提だった。

新しく、参考デザイン (円環状に並ぶ発光したバー / 黒背景 / 虹色) を実装したい。
論点は 2 つ:

1. 既存のスペクトラム描画とどこまで実装を共有するか
2. 背景がグラデーションのままでは発光表現が成立しない問題をどう扱うか

## 決定

### 1. 値の生成は共有し、配置と発光だけを新しい型に持たせる

`RadialSpectrumCanvas` を `Visual/` に追加し、バー値は既存の
`SpectrumCanvas.logBars(magnitudes:sampleRate:barCount:)` をそのまま呼ぶ。

理由:

- 対数周波数軸へのまとめ方と dB 正規化は「どう並べるか」とは独立した関心事で、
  リング表示でも同じ値が欲しい。複製すると 2 か所で正規化のパラメータがずれる。
- 結果として新しい型が持つのは **配置 (極座標への写像) と発光の表現だけ** になり、
  純関数 (`mirrored` / `sourcePosition` / `endpoints` / `barColor`) として単体テストできる。

`SpectrumCanvas` 側は変更していない。既存モードの見た目に影響を出さないため。

### 2. 左右対称 + 天頂を「バーの隙間」に置く

参考デザインは左右対称なので、半周ぶんのバー (低域→高域) を鏡像展開して一周にする。

配置角は `(index + 0.5) / count` 回転とし、天頂と真下がバーの中心ではなく
**バーとバーの隙間**に来るようにした。ここを半スロットずらさないと、鏡像展開したときに
天頂で同じ値のバーが 2 本隣接し、左右対称にならない。

### 3. 内周をバー値で押し出す

内周を真円に固定すると「棒が生えた円」にしかならず、参考デザインの
輪郭がうねる印象が出ない。バー値に比例して内周を押し出す (`ringDeform`) ことで、
鳴っている帯域の方向へ輪郭が膨らむ。

さらに低域エネルギーでリング全体を膨らませ (`pulseDepth`)、拍で脈打たせている。

### 4. 発光は「ぼかした同じ絵を下に敷く」1 レイヤーで作る

`GraphicsContext.drawLayer` + `.blur` フィルタで同じバー群を 1 回だけ描き、その上に
本体を描く。バー 1 本ごとに影を付ける方式に比べ、バー数が増えても描画コストが
「レイヤー 1 枚ぶん」で頭打ちになり、見積もりやすい。

### 5. 背景の暗転は表示モードから導出する

発光表現は「背景より明るい」ことで成立するため、既存のグラデーション背景のままだと
バーが背景に沈む。

背景スタイルを独立した設定項目にすると「リング + 明るい背景」という破綻した組み合わせを
ユーザーが作れてしまうので、`DisplayMode.prefersDarkBackground` としてモードから導出する
形にした。リング選択時はほぼ黒 + 中心にだけ現在色を薄く残す背景に切り替わる。

### 6. 設定はチューニングパネルの表示セクションから切り替える

モードの `Picker` に `.radial` を足しただけで切り替えられる。ただしセグメント表示は
4 つの日本語ラベルでは潰れるため、既定のスタイル (メニュー) に変更した。

リング固有のパラメータ (バー本数 / 半径 / 長さ / 色相の一周量 / 発光 / 拍 / 回転) は
`VisualizerSettings.RadialSettings` にまとめ、**リング選択時だけ**セクションを出す。
他モードでは効かない値を常時見せると、どれが効いているのか分からなくなるため。

## 影響

- `DisplayMode` の判定を `!= .spectrum` のような否定形から
  `showsWaveform` / `showsLinearSpectrum` / `showsRadialSpectrum` という明示的な述語に変えた。
  否定形のままだと `.radial` を足した瞬間に「リングなのに波形も描かれる」バグになる。
- `VisualizerEngine` と DSP 層は無改修。リングは `AnalysisResult` の
  `magnitudes` と `energy.low` しか見ていない。

## 代替案

- **Metal で描く**: パーティクルや残像まで踏み込むなら必要だが、今回のバー数
  (既定 56 × 2 = 112 本) は Canvas で足りる。まず Canvas で成立させ、実機で
  フレームレートが落ちたら移行する (README の既知の制約に既に記載がある方針)。
- **既存 `SpectrumCanvas` に「円形モード」を足す**: 引数と分岐が増えて、
  直交しない設定 (円形のときだけ意味のある半径など) が 1 つの型に溜まる。分けた。
